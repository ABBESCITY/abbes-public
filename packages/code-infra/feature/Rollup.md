# Rollup 编译打包架构设置

## 为什么用 Rollup

由于 esbuild、tsup 对于样式文件和声明类型的文件的打包和编辑支持不是很好，而 Rollup 针对这些的处理的很好，还有处理这些文件的中间件，以及参考所提到的优秀的树摇功能。

## 使用 Rollup 的场景

- 对于前端工具库的编译打包
- 对于前端组件库的编译打包

## 参数设定

1. `multiple` 多配置模式，针对于一个项目中同时打包多个包。
   1. `packageName` 没有统一入口形式的打包，针对有明确界定的子模块项目进行打包。
   2. `split` 没有统一入口形式的打包，针对有明确界定的子模块项目进行打包。
